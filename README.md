# 💡 Идеи Batumi Vibe Lab

Здесь собираются идеи проектов клуба. Одна идея — один issue. Торопиться некуда: идея может ждать своего часа сколько угодно.

[Предложить идею](https://github.com/batumi-vibe-lab/ideas/issues/new/choose) · [Все идеи](https://github.com/batumi-vibe-lab/ideas/issues) · [Самые поддержанные](https://github.com/batumi-vibe-lab/ideas/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc)

## ✍️ Предложить идею

Нажми **New issue → 💡 Новая идея** и коротко заполни форму — детали можно добавить позже. Метки поставятся сами.

## 🗣 Обсуждение

- Поддержать идею — 👍 под описанием.
- В комментариях — вопросы, советы, ссылки и предложения помочь.
- Обсуждали идею на встрече? Будет здорово, если кто-то коротко запишет итоги в комментарий.

Метки меняют контрибьюторы. Если какая-то устарела, напиши в комментарии — поправим.

## 🏷 Метки

| Группа  | Значения                                                   | Что значат                                                                     |
| ------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Стадия  | `идея` → `проверка` → `разработка`                         | Есть описание → проверяем спрос → пишем код в `proj-*`                         |
| Цель    | `заработать` · `польза` · `эксперимент`                    | Ради денег · для города и сообщества · чтобы научиться                         |
| Рынок   | `Батуми` · `вайб-клуб` · `любой` · `другое место`          | Город и его жители · сам клуб · без привязки к месту · другой город или страна |
| Команда | `нужен владелец` · `нужны люди` · `команда укомплектована` | Ищем, кто поведёт · ищем, кто присоединится · люди сейчас не нужны             |

На GitHub метка выглядит как группа и значение: `стадия: идея`, `рынок: Батуми`.

Хочешь повести проект — загляни в [нужен владелец](https://github.com/batumi-vibe-lab/ideas/issues?q=is%3Aissue+is%3Aopen+label%3A%22%D0%BD%D1%83%D0%B6%D0%B5%D0%BD+%D0%B2%D0%BB%D0%B0%D0%B4%D0%B5%D0%BB%D0%B5%D1%86%22). Ищешь, к чему присоединиться, — в [нужны люди](https://github.com/batumi-vibe-lab/ideas/issues?q=is%3Aissue+is%3Aopen+label%3A%22%D0%BD%D1%83%D0%B6%D0%BD%D1%8B+%D0%BB%D1%8E%D0%B4%D0%B8%22).

## 🚀 Когда начинается работа

Под проект заводим репозиторий `proj-<название>`, а issue идеи остаётся открытым и собирает историю.

- В README проекта — ссылка на идею: `batumi-vibe-lab/ideas#12`.
- В PR и коммитах — `Refs batumi-vibe-lab/ideas#12`, тогда работа видна в ленте идеи. `Closes` здесь не подходит: он закроет идею после первого же PR.
- Задачи проекта можно добавить к идее как подзадачи — на её странице появится прогресс.

Идеи, взятые в спринт, отмечаем milestone спринта.

## 🏁 Завершение

- Проект запущен — **Close as completed** и ссылка на результат.
- Решили не делать — **Close as not planned** и пара слов почему: это поможет тем, кто придёт с похожей идеей. Закрытую идею всегда можно открыть снова.
- Такая идея уже есть — **Close as duplicate**.

> 🔒 Репозиторий приватный: идеи участников остаются внутри клуба, пока авторы не решат иначе.
